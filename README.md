# Full-Stack Authentication Project

A Node.js, Express, and MySQL user authentication application with JWT cookies and a responsive dashboard UI.

## Features
- User Registration & Login
- JWT Cookie Authentication
- Profile Management & Password Reset
- Account Deletion

## How to Run

1. Clone the repository
2. Run `npm install`
3. Copy `.env.example` to `.env` and fill in your database details
4. Run `npm start`
5. Open `http://localhost:1111` in your browser
